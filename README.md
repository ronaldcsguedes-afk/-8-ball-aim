# 8 Ball Aim Simulator

Projeto Android nativo em Kotlin: simulador independente para treino de mira em uma mesa de bilhar ilustrativa.

## Abrir e gerar APK
1. Instale o Android Studio em um computador.
2. Abra a pasta `8BallAimSimulator` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Conecte um celular Android ou use um emulador para testar.
5. Para gerar o APK: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. O Android Studio mostrará o caminho do APK gerado.

## Como usar
Toque em qualquer ponto da mesa para mudar a direção da linha de mira.

## Limites
Este é um simulador de treino independente. Não se conecta ao 8 Ball Pool, não lê a tela do jogo e não automatiza jogadas.
